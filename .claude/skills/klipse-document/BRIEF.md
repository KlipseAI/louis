# 문서 브리프

> 이 파일을 채워 주면 문서를 짠다. 모양은 정해져 있다 — 무엇을 말할지만 적는다.
> 비워 둔 칸은 묻거나, 문서 안에 「〔채울 자리: …〕」로 남겨 검사가 잡게 한다. 수치를 지어내지 않는다.

## 1. 기본

- 제목:
- 발행 주체(팀 · 조직):
- 기준 날짜:
- 읽는 사람: (예: 대표 · 팀 내부 · 고객사)
- 성격: 운영안 · 결과 보고 · 제안서 · 회고 (하나)

## 2. 결론 한 문장

다 읽은 사람이 무엇을 알거나 정하기를 바라는가.

## 3. 정할 것 (있으면)

수치 · 비교 · 순서 · 일정이 있으면 표시해 준다 — 알맞은 부품(격자 · 막대 · 표 · 흐름 · 타임라인)을 고른다.
