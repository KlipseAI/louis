# Voice & Tone

Klipse 이름으로 밖에 내보내는 글의 어조를 정합니다. 카드뉴스, 인스타그램 게시물, 공지, 업데이트 소식이
대상입니다. 보고서, 운영안, 제안서 같은 LOUIS 문서([Document 패턴](../patterns/document.md))도 같은 공식 톤으로
씁니다.

제품 화면 문구는 이 문서의 대상이 아닙니다. 화면 문구는 [Content & Localization](README.md)의 기본 원칙을
따르고, 사용자가 할 행동을 쉬운 말로 씁니다.

## 공식 톤

- 합니다체로 씁니다.
- 변경과 추가를 알릴 때는 구어 동사 대신 공식 표현을 씁니다.
- 기능은 사용자가 할 수 있는 일로 설명합니다. 「~할 수 있습니다」, 「~을 확인할 수 있습니다」처럼 씁니다.

| 쓰지 않는 표현 | 쓰는 표현 |
| --- | --- |
| 새 모델이 들어왔습니다 | 새 모델을 지원합니다 |
| 새 기능이 생겼습니다 | 새 기능이 추가되었습니다 |
| Lite 플랜이 생겼습니다 | Lite 플랜이 출시되었습니다 |
| 화면이 바뀌었습니다 | 화면이 변경되었습니다, 화면이 개편되었습니다 |
| 해상도를 고릅니다 | 해상도를 선택할 수 있습니다 |
| 지표를 봅니다 | 지표를 확인할 수 있습니다 |
| YouTube 쇼츠로 올립니다 | YouTube 쇼츠로 업로드합니다 |
| 아이콘을 새로 그렸습니다 | 아이콘이 새로 디자인되었습니다 |
| 크레딧이 사라지는 날짜 | 크레딧 소멸 일정 |
| 새 기능을 써 보세요 | 새 기능을 사용해 보세요 |

표에 없는 표현도 같은 기준으로 정합니다. 한 곳을 고치면 같은 결의 표현을 글 전체에서 함께 고칩니다.

## 글의 짜임

카드뉴스와 업데이트 소식은 아래 순서를 따릅니다.

- 제목은 무엇이 달라졌는지 한 문장으로 씁니다. 예: 「카메라 앵글 기능이 추가되었습니다」.
- 본문은 어디서 어떻게 쓰는지와 숫자를 씁니다. 예: 「길이를 3초부터 15초까지 선택할 수 있습니다.」
- 마지막 장은 한 문장으로 끝냅니다. 예: 「지금 Klipse에서 새 기능을 사용해 보세요」.

## 쓰지 않는 것

- 구어 동사로 알리는 문장(들어왔습니다, 생겼습니다, 바뀌었습니다, 올립니다)
- 비유와 감성 문구
- 응원, 안심, 인사치레 문구. 예: 「거의 다 왔어요」, 「괜찮아요」, 「1분이면 끝나요」
- 가운뎃점(·, •)으로 낱말을 잇는 것. 쉼표와 「와」, 「과」로 잇습니다.
- 말줄임표
- 「~죠」, 「당신」

## 사실

- 숫자(가격, 크레딧, 해상도, 길이)와 이름(플랜, 모델, 메뉴, 탭, 노드)은 제품 화면과 코드에 적힌 그대로 씁니다.
  표기도 화면과 같게 씁니다. 예: 「비디오 노드」, 「768p」, 「2K」.
- 「추가되었습니다」와 「출시되었습니다」는 그 기간에 처음 나온 것에만 씁니다. 전부터 있던 기능이 나아졌으면
  「개선되었습니다」, 「확대되었습니다」, 「개편되었습니다」로 씁니다. 기능이 언제 처음 나왔는지는 머지 이력으로
  확인합니다.
- 기간이나 대상에 제한이 있는 기능은 그 제한을 함께 씁니다. 제한을 빼면 언제나 되는 것으로 읽힙니다.
  예: 「크레딧을 사용하지 않은 결제에 한해 충전은 7일, 구독은 24시간 안에 청약철회를 신청할 수 있습니다.」
- 숨김 처리된 기능과 아직 운영에 나가지 않은 기능은 쓰지 않습니다. 글에 넣는 제품 화면에도 보이지 않게 합니다.

## 예시: 2026년 9월 업데이트 카드뉴스

처음에 쉬운 말로 썼던 문구를 공식 톤으로 고친 것입니다.

| 처음 문구 | 고친 문구 |
| --- | --- |
| 새 모델이 들어오고 선택지가 늘었습니다 | AI 모델이 업데이트되었습니다 |
| MiniMax H3와 GPT Image 2.5가 들어왔습니다. | MiniMax H3와 GPT Image 2.5를 지원합니다. |
| 캔버스에 새 기능이 생겼습니다 | 캔버스에 새 기능이 추가되었습니다 |
| 요금제와 구독 화면이 바뀌었습니다 | 요금제와 구독 화면이 변경되었습니다 |
| 남은 크레딧과 사라지는 날짜를 봅니다 | 남은 크레딧과 소멸 일정을 확인할 수 있습니다 |
| 길이를 3초부터 15초까지 고릅니다. | 길이를 3초부터 15초까지 선택할 수 있습니다. |
| 지금 Klipse에서 새 기능을 써 보세요 | 지금 Klipse에서 새 기능을 사용해 보세요 |
