# 장표 규약 (비규범)

1920×1080 발표 장표의 판형·여백·마스터 규약이다. **제품 UI가 아니라 장표용**이며 이 저장소의
component 계약과 별개다. 다른 사본이 없어 보존한다.

`Klipse 서비스 소개서 KOR` 93장을 실측해 확정된 값이다. 장표를 그린다면
[deck-structure.md](deck-structure.md)와 [layout-rules.md](layout-rules.md)를 먼저 연다 —
판형·여백·마스터 위치·간격이 거기 있다.

| 파일 | 무엇 |
| --- | --- |
| [SKILL.md](SKILL.md) | 작업 규약 진입점 |
| [deck-structure.md](deck-structure.md) | 판형 1920×1080 · 여백 100 · 본문 영역 · 마스터 위치 |
| [layout-rules.md](layout-rules.md) | 배치 규칙 |
| [chart-style.md](chart-style.md) · [imagery.md](imagery.md) · [information-hierarchy.md](information-hierarchy.md) · [copy-tone.md](copy-tone.md) | 각 축의 규약 |

**표지 제목과 강조 숫자에 쓰는 `Type/Display/64`는 장표 전용이며 코드에 없다** — 웹앱에 1920
고정폭 화면이 없기 때문이다. 이 스타일을 제품 typography 계약으로 읽지 않는다.
