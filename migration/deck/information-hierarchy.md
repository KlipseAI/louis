# 정보 위계

타이포 스케일은 `design/llms/foundations.txt` 가 원본이다. 여기에는 **어느 단계를 어디에 쓰는가**만 적는다.

## 단계는 7개뿐이다

`heading 48 / 36 / 28` · `body 20 / 16 / 14` · `caption 12`.
**이 표에 없는 크기는 존재하지 않는다.** 굵기는 regular(400) · medium(500) · semibold(600) 셋이고 bold 는 없다.

## 역할

| 단계 | 쓰는 곳 |
| --- | --- |
| `heading-48` | 페이지·장표의 유일한 주제. 한 화면에 하나 |
| `heading-36` | 섹션 제목, auth 브랜드 슬로건 |
| `heading-28` | 블록 제목, 모달 제목 |
| `body-20` | 리드 문장 — 제목을 한 문장으로 풀 때 |
| `body-16` | 본문 기본. 메뉴 라벨 |
| `body-14` | 조밀한 본문, 표 셀, 노드 라벨 |
| `caption-12` | 메타·보조 설명·칩 라벨 |

## 위계를 만드는 순서

1. **크기 → 굵기 → 색** 순으로 차이를 준다. 세 가지를 동시에 바꾸지 않는다.
2. 색만으로 위계를 만들 때는 `content/primary` → `secondary` → `tertiary` 순으로 내린다.
3. 같은 단계를 두 번 연속 쓰면 위계가 아니라 나열이다. 나열이면 굵기·색을 통일한다.

## 한 화면·한 장표

- **주장 하나.** heading 은 하나만, 나머지는 그 아래 단계로 내려간다.
- 제목은 명사구로 끊고 설명은 `body-20` 이하로 붙인다.
- 강조는 semibold 로 한다. 색 강조는 `brand/primary` 나 `status/*` 만 쓰고 임의 색을 만들지 않는다.
- 숫자·수치는 크기를 올리기보다 굵기를 올린다. 크기를 올리면 위계가 무너진다.

## 반응형

`heading-48 → 36 → 32 → 28`, `heading-36 → 32 → 28 → 20`, `heading-28 → 20 → 18`, `body-20 → 18 → 16`.
이 램프는 `[data-page-root]` 스코프에만 적용된다 — 앱·대시보드에서는 크기가 고정이다.
