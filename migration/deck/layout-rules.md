# 판형 · 그리드 · 여백

값의 원천은 `design/llms/foundations.txt` 와 `design/tokens.yaml` 이다. 여기에는 **어떤 판형을 쓰는가**만 적는다.

## 공통

- **간격은 2px 그리드.** `--spacing: 2px` 이므로 Tailwind 유틸 숫자는 절반이다 — `p-4` = 8px, `w-14` = 28px.
- 레이아웃·간격·블러·반경은 **px**. `rem` 을 쓰지 않는다.
- 박스 스트로크는 **0.5px**. 노드 카드 최외곽만 2px.
- 반경은 px 스케일(`rounded-2 … rounded-24`)과 `rounded-full`(999px).
  **액션 버튼은 12px**, pill(999px)은 글래스 칩·툴바 알약 전용.

## 제품 UI

| 판형 | 값 |
| --- | --- |
| 데스크톱 뷰포트 (Figma 목업 기준) | **1440 × 810 (16:9)** |
| 앱 셸 최소 폭 | `--app-shell-min-width` 960px |
| 사이드바 | `min(280px, 100vw - 120px)` · 접힘은 padding-x × 2 + menu-hit-w |
| main 좌우 패딩 | 16px / 12px (`--app-gnb-main-inline-padding`, `-end`) |
| 컴포저 | `min(100%, 560px)` → ≤720px `min(100%, 520px)` + padding-inline 16 → ≤480px `100%` |
| 화면 가장자리 여백 | 12px (safe-area 고려: `max(12px, env(safe-area-inset-top))`) |

브레이크포인트: **1023 · 767 · 719 · 479 · 450**.
타입 램프는 `[data-page-root]` 스코프에서만 작동한다 — 앱·대시보드는 영향받지 않는다.

## 문서 · 장표

- **1920 × 1080 (16:9).** 제품 화면 목업(1440×810)과 같은 비율이라 축소해 그대로 얹을 수 있다.
- **좌우·상하 여백 100, 본문 컬럼 1720.** 헤더 영역 100–380, 본문 380–980, 하단 980–1080 은 출처 밴드.
- **박스 사이 간격 10.** 컴포넌트 내부 간격은 컴포넌트 정의를 따르며 장표에서 덮어쓰지 않는다.
- 화면 캡처를 넣을 때 **비율을 바꾸지 않는다.** 잘라내되 늘이지 않는다.
