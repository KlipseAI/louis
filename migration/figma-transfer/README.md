# Figma 이관 기록 (비규범)

제품 화면을 Figma로 옮기려 한 이전 시도의 기록이다. **규범이 아니라 겪은 일**이며, 같은 함정을
다시 밟지 않기 위해 보존한다. 이 저장소 어디에도 사본이 없던 문서들이다.

| 파일 | 무엇 |
| --- | --- |
| [FIGMA-FEEDBACK.md](FIGMA-FEEDBACK.md) | **22차에 걸친 왕복.** 문서만 읽고 Figma에 그리다 막힌 자리를 회차마다 적었다 |
| [RESUME.md](RESUME.md) | 사양 작성 쪽의 중단 지점과 저지른 실수 5건 |
| [NEXT-SESSION.md](NEXT-SESSION.md) | Figma 담당 세션에 넘기던 인계문 |
| [figma-board-2026-08-09.txt](figma-board-2026-08-09.txt) · [.json](figma-board-2026-08-09.json) | 그 시점 **Figma 보드의 상태**. 코드에서 파생되지 않는 유일한 입력이라 복구할 수 없다 |

## 왜 값진가

`FIGMA-FEEDBACK.md`는 **그리는 쪽이 실제로 막힌 자리**의 기록이다. 문서를 읽고 「부족해 보인다」고
말한 것이 아니라, 그리다가 값이 없어서 멈춘 지점이다. 그런 자리는 재측정으로는 나오지 않는다 —
무엇을 재야 하는지 모르기 때문에 안 재는 것이다.

`RESUME.md`의 「내가 실제로 저지른 실수」 5건도 같은 성격이다. 첫 항목이
**「게이트 오탐을 믿고 맞는 값을 틀리게 바꿨다」**이고, 그 뒤 라운드에서 나온 빨간불 3건이
**3건 다 게이트 쪽 오탐**이었다고 적혀 있다. 이 저장소의
[불확실 값 명부](../../figma/unverified-values.json)가 말하는 것과 같은 병이다.

## 신뢰도

**좌표와 값은 낡았을 수 있다.** 2026-08-08~09 시점 기록이고 그 뒤 제품이 움직였다.
값을 가져다 쓰지 말고 **어디서 막혔는지**만 읽는다. 값이 필요하면 실측 하네스로 다시 잰다.

## Figma 보드 스냅샷에 대해

`figma-board-2026-08-09.*`는 **그 시점 보드를 전사한 것**이고, 다른 문서와 방향이 반대다 —
나머지는 코드에서 생성되지만 이것만 Figma에서 나온다. 그래서 **코드에 있는데 보드에 없는 것은
여기 안 나오고, 보드에만 있고 코드에 없는 것이 섞여 있다.** 그 시점 문서 자신이 「역할 이름 35개
중 9개만 CSS 변수로 존재한다」고 적어 두었다.

현재 보드 상태는 [`figma/snapshot.json`](../../figma/snapshot.json)이 소유하며 게이트가 지킨다.
이 파일은 **과거 상태의 기록**이지 현재의 근거가 아니다.
