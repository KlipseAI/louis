## Color — roles (Figma Semantic 컬렉션)

Semantic 컬렉션. Light / Dark 두 모드이며 값은 Primitives 팔레트의 별칭이다. 노드 안 톤 사다리 (palette-gray 스톱, 라이트/다크): 카드 raised 100/800 → 입력 박스 input 50/700 → 입력 외곽선 border-input 000/600 → AI 답변 버블 answer 150/600(외곽선 없음) → 메타 버튼 inset 100/600 → 메타 버튼 외곽선 border-control 150/500. 다크는 카드에서 한 톤씩 밝아지고, 라이트는 입력 박스만 카드보다 밝고 나머지는 어두워진다. surface/selected 는 사이드바 등에서 현재 선택된 항목의 면 — 라이트 palette-gray/300 · 다크 palette-gray/800 이며, Gnb.tsx 의 menuSidebarActiveIndicator 와 같은 값이다. surface/inset(라이트 100 · 다크 600)과 혼동하지 말 것. surface/cta-inverse·content/on-cta-inverse 는 사이드바 업그레이드 CTA (라이트 900/100 · 다크 100/900); 기본 상태는 mint 가 아니라 이 값이다 — mint 는 /mypage/upgrade 에서만 나온다. content/on-media 는 카드 썸네일 위 오버레이 전경(라이트 palette-gray/900 · 다크 100)으로, 썸네일 위지만 앱 테마를 따른다.

## Shape & Space

--spacing = 2px — Tailwind 유틸 숫자는 2배가 아니라 절반이다. p-4 는 8px, w-14 는 28px.
radius 는 px 스케일: rounded-2 4 6 8 10 12 14 16 20 24, rounded-full=999px.
Tailwind 기본 이름(rounded-lg, text-sm 등)은 제거되어 존재하지 않는다.
박스 스트로크는 0.5px. 노드 카드 최외곽만 2px.

## ⚠ 토큰 이름이 종류를 뜻하지 않는다

`shadow` / `frame` 이 들어 있다고 드롭섀도우가 아니다. 아래 `종류` 는 **이름이 아니라
해결된 값에서 뽑은 것**이다 — 각 레이어의 blur·spread·inset 을 보고 판정한다.

glass-bevel-highlight
  종류: 안쪽 베벨(하이라이트/음영)
glass-bevel-shade
  종류: 안쪽 베벨(하이라이트/음영)
dropdown-ambient-shadow
  종류: 드롭섀도우 (blur 15px)
node-meta-dropdown-shadow
  종류: 드롭섀도우 (blur 15px) + 헤어라인 링 (blur 0, spread 0px)

## ⚠ 오버라이드된 기본값 — 정의를 읽으면 틀리는 자리

아래 규칙들은 **자기 자신이 아니라 다른 클래스**를 덮는다. Tailwind 는 소스 스캔으로
CSS 를 내보내므로 이 규칙은 그 배리언트가 화면에 붙었는지와 상관없이 **항상 존재**하고,
선택자가 길어 베이스보다 명시도가 높다. 결과적으로 **덮인 값이 실제 기본값**이다.

**베이스 정의만 보고 옮기면 안 된다.** 아래 대상 클래스는 여기 적힌 값이 배포 화면의 값이다.

### .gnb-menuLink  (components/navigation/Gnb.tsx)
  베이스 정의(이 값이 화면에 안 나온다):
    background: transparent  light→ transparent  dark→ transparent
    color: var(--gray-000)  light→ #000000  dark→ #fafafa
  ↓ 아래 규칙이 이를 덮는다 — **아래가 실제 기본값이다.**

## Figma 등 다른 도구로 그대로 옮길 수 없는 것

**근사치를 지어내지 말 것.** 아래는 CSS 에서만 성립한다. 옮기는 쪽에서는 재현이 아니라
`재현 불가` 로 표시하고 코드를 원천으로 두어야 한다.

- **backdrop-filter (뒤 배경 블러) — 66개 파일.** 뒤에 실제로 무엇이 있느냐에
  따라 결과가 달라진다. 단색 채우기로 대체하면 다른 화면이 된다.
  사용처: app/admin/AdminClient.tsx · app/admin/BannerManagement.tsx · app/admin/BlogManagement.tsx · app/admin/InquiryManagement.tsx · app/admin/JobMonitor.tsx · app/admin/ProductMetricsDashboard.tsx …
- **그라디언트 마스크 — 23개 파일.** 블러/이펙트에 알파 그라디언트를 씌우는 형태로,
  Figma 의 레이어 마스크로는 블러 강도가 점진적으로 변하는 부분이 재현되지 않는다.
  사용처: app/HomePageClient.tsx · app/admin/BannerManagement.tsx · app/admin/TemplateManagement.tsx · app/mypage/upgrade/page.tsx · components/banners/TabBannerCarousel.tsx · components/landing/demo-snapshots/StaticGnb.tsx …
- **테마를 따라가지 않는 값.** 위 그림자 토큰들은 `:root` 에만 있고 다크 재정의가 없다 —
  즉 **다크에서도 같은 값**이다. 다크용 변형을 새로 만들면 코드와 갈린다.
- **`@layer` 밖 규칙이 유틸리티를 이긴다.** 명시도와 무관하다. 옮길 때 `!` 가 필요한 자리는
  스타일 결정이 아니라 이 우선순위 때문이며, 다른 도구에는 대응 개념이 없다.
