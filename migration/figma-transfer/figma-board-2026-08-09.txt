# Klipse Design System — Components

Figma 에 정의된 컴포넌트와 배리언트·속성. 새 UI 는 여기 있는 것을 먼저 찾아 재사용하세요.

원천: apps/web/app/globals.css · apps/web/app/tailwind.css · Figma "Klipse 3.0"
생성: pnpm --filter web build-llms-docs — 이 파일을 직접 고치지 마세요.

> **이 문서의 원천은 Figma 다.** 다른 문서(foundations · patterns)는 globals.css 에서 생성되지만
> 이 파일은 Figma 보드를 전사한 것이라, **코드에 아직 없는 것이 섞여 있다.**
>
> - 아래 설명에 나오는 `surface/*` `content/*` `border/*` `interaction/*` `status/*` `brand/*` 역할 이름은
>   **Figma 의 이름**이다. 35개 중 9개만 CSS 변수로 존재한다 —
>   구현 여부는 foundations.txt 의 `## Color — roles` 절에서 `[코드]` / `[Figma 전용]` 표시를 확인할 것.
> - 코드를 쓸 때 이 파일의 역할 이름을 그대로 옮기지 말 것. 실제 토큰을 쓴다.
> - 반대로 **코드에는 있는데 Figma 보드에 없는 컴포넌트는 이 목록에 나타나지 않는다.**
>   이 파일이 비었다고 그 컴포넌트가 없는 것은 아니다.

### Button  (COMPONENT_SET)
범용 액션 버튼. 코드 토큰을 그대로 쓴다:
높이 --button-height 40 / --button-height-sm 32 · radius --button-radius 12 ·
좌우 --button-padding-inline 16 / -sm 12 · 최소 폭 --button-min-width-sm 48.
Tone=Primary 는 단색이 아니라 --node-prompt-generate-gradient 다 — linear-gradient(90deg, #1491ff 0%, #0088ff 50%, #1491ff 100%). 노드 생성 FAB 과 같은 SSOT.
이너섀도우 3겹: 글래스 베벨 inset 0 ±1px 1px 흰 25% 두 겹 + ::before 이너 글로우 inset 0 0 8px 흰 100%(mix-blend-overlay).
단색 파랑으로 그리면 틀린다 — 그라디언트와 이너 글로우가 이 버튼의 정체다.
호버는 어두워지지 않고 밝아진다(filter: brightness(1.06)).
Tone=Secondary(0.5px 아웃라인) · Ghost(면·선 없음) · Danger(status/danger).
pill(999)은 글래스 칩·툴바 알약 전용 — 액션 버튼은 항상 12px.
variant Tone: Primary | Secondary | Ghost | Danger
variant Size: Default | Small
property Label: TEXT

property Description: TEXT
