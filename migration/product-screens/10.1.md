### 10.1 홈·아카이브 (`/archive` — AppHomeScene)

로그인 후 기본 착지 화면이다. 미들웨어가 랜딩·로그인·회원가입에 접근한 로그인 사용자를 여기로 보내고, 비로그인 사용자가 여기 오면 `/login` 으로 되돌린다(`middleware.ts` matcher `"/archive/:path*"`).

**셸(사이드바 오프셋 · 카드 크롬 · 스크롤 모델 · 719px 분기)은 6.13절 「형태 A」 그대로다.** 버튼은 **6.10절**, 좌측 사이드바 항목은 **6.3절**, 드롭다운 표면 토큰(`--dropdown-*`)은 **6.5절**, 글래스 프레임·베벨은 **6.1절**, 라이트 앱 셸의 회색 램프 재매핑(`html[data-theme=light] body:has(.gnb-wrapperSidebar)`)은 **6.13절**을 따른다. 이 절의 라이트 값은 전부 그 시프트 **후** 값이다.

> **가장 자주 나는 사고는 `appHomeSceneStyles.ts` 를 인벤토리로 읽는 것이다.**
> 그 파일에는 이 라우트가 렌더하지 않는 스타일이 12개 들어 있다(아래 「이 화면에 없는 것」).
> 하단 플로팅 「새 프로젝트」 버튼과 카드 생성-진행 오버레이를 문서에서 되살리면 배포 화면과 달라진다.

**`rightControls` 에서 실제로 상속되는 것**: `position: relative` · `z-index: 1` · `appearance/-webkit-appearance: none` · `border: 0` · `cursor: pointer` · `display: inline-flex` · `align-items: center` · `color: inherit` · `transition: filter 180ms ease` · **`:hover { filter: brightness(112%) }`** · `@media(max-width:480px){ order: 1 !important }`.
`gap` · `padding` · `border-radius` · `box-shadow` 는 `[&:not(.gnb-profileTrigger)]:` 가드가 붙어 애초에 걸리지 않는다.
**`background-color: rgb(var(--gray-000-rgb)/10%)` 와 `backdrop-filter: blur(10px)` 에는 가드가 없다** — 같은 특이도(0,1,0)라 출력 순서로 갈리고, 산출 CSS 에서 `[background:transparent]`(오프셋 281184)와 `[backdrop-filter:none]`(225133)이 각각 `[background-color:…10%]`(110030)·`[backdrop-filter:blur(10px)]`(224127)보다 뒤에 실려 **profileTrigger 가 이긴다 → 실제로 투명·블러 없음.**

**링 진행률**: 클래스 기본은 `0%` 이고 실제 값은 Gnb 가 인라인 `style={{ "--profile-ring-progress": `${profileTokenRingProgress}%` }}` 로 주입한다.
산식 — 랜딩 데모면 50; 아니면 `totalGranted = credit_pools.plan.granted + credit_pools.topup.granted`, `totalRemaining` 은 같은 방식의 remaining 합. `totalGranted <= 0` 이면 `billing.available_token_amount` 가 truthy 일 때 **100**, 아니면 **0**. 그 외 `max(0, min(100, totalRemaining / totalGranted * 100))`.

**아바타 이미지**: `<GnbProfileAvatar src={profileImageSrc} className={profileImage}>`, `profileImageSrc = profile?.avatar_url ?? "__default_avatar__"`.

- 기본값이면 `<UserCircleDefaultAvatar>` — `<span class="inline-flex items-center justify-center box-border w-14 h-14">`(**28×28**) + 인라인 SVG `viewBox="0 0 20 20"` `class="block w-full h-full"`, 단일 `fill="currentColor"` path(원 + 인물 실루엣, `fillRule`/`clipRule` evenodd), `aria-hidden` + `role="presentation"`.
  색 `text-palette-gray-400` / `dark:text-palette-gray-600` → **라이트 시프트 후 #d5d7dd · 다크 #777d89**. (파일 주석의 `#BCC0C9` 는 시프트 전 값이다.)
- URL 이 있으면 `next/image` `width=112 height=112`.
- `profileImage` 클래스: `width/height: var(--profile-avatar-size)!`(28px) · `border-radius: 999px` · `flex-shrink: 0` · `box-sizing: border-box` · `object-fit: cover` · **`display: block!`**(공용 아바타 문자열의 `inline-flex` 를 이기려고 `!`).

> **ref 가 아직 null 인 첫 렌더에서는 Gnb 가 fixed 폴백을 그리지 않고 아무것도 렌더하지 않는다.** 헤더가 카드 밖에 떠 있는 스크린샷은 이 화면의 참조가 아니다.

#### 좌측 사이드바에서 이 화면이 결정하는 것

##### 활성 항목의 슬라이딩 인디케이터

`<span class="gnb-menuSidebarActiveIndicator" aria-hidden>` 은 `menuSidebarOuter` 안 `<ul>` **앞**에 렌더되며, **첫 측정 전에는 아예 mount 되지 않는다**(인라인 `transform` 이 있어야 렌더). 항목 자체의 배경은 transparent 이고, /archive 에서 사이드바 「홈」 항목이 배경을 가진 것처럼 보이는 것은 전적으로 이 사각형이다.

| 항목 | 값 |
| --- | --- |
| 배치 | `position: absolute` · `top: 0` · `left: 0` · **`z-index: 0`** · `pointer-events: none` · `box-sizing: border-box` |
| 형태 | **`border-radius: 10px`** · `transform-origin: 0 0` · `will-change: transform` · 기본 `opacity: 0` |
| 색 | 라이트 `background-color: var(--palette-gray-300)` → **시프트 후 #e4e5e9** · 다크 `var(--palette-gray-800)` = **#313640** |

#### CreateProjectModal (노드캔버스 생성)

##### 닫는 방법

**오버레이 아무 곳이나 클릭하면 닫힌다** — ROOT 의 `onClick={handleClose}` 이고 카드가 `stopPropagation` 으로 막는다. 취소 버튼(`type="button"`, `disabled={isSubmitting}`)도 같은 `handleClose` 를 부른다.

`handleClose()` 는 **`isSubmitting` 이면 즉시 `return`** — 제출 중에는 백드롭 클릭도 취소 버튼도 무효다.

> **Escape 핸들러도, 포커스 트랩도, body 스크롤 잠금도 없다.** 파일 전체에 keydown 리스너가 하나도 없다. 바로 옆의 `HighlightCreateModal` 은 Escape 를 걸고 있으므로 **대칭으로 유추하면 틀린다.**

닫힘은 즉시 언마운트가 아니다 — `syncMotion()` 을 한 번 더 돌려 현재 트리거 위치를 다시 재고 `isVisible = false` 로 역모션을 재생한 뒤 `setTimeout(…, 280)` 후 `shouldRender = false`. 언마운트 시 `projectName` · `isSubmitting` · `errorMessage` 를 리셋한다. 열릴 때는 `projectName`/`errorMessage`/`showUpgrade` 초기화 후 rAF 한 번 뒤 `inputRef.focus()`.

translateY = (트리거 rect 중심Y) − (카드 rect 중심Y)
scaleX     = min(max(buttonRect.width  / cardRect.width,  0.18), 0.34)

##### 키보드 · 스크롤

패널 `onKeyDown`: `Escape` → 서브메뉴가 열려 있으면 그것만 닫고 아니면 `onClose()`(preventDefault + stopPropagation). `ArrowDown`/`ArrowUp` → 서브메뉴가 열려 있으면 `subIndex`, 아니면 `activeIndex` 를 **순환**. `ArrowLeft` → 서브메뉴 닫기. `ArrowRight` → 서브메뉴 열기. `Enter` → 서브메뉴면 `activateSub`, 아니면 `activate`.
`activate(item)`: 서브메뉴가 있으면 같은 항목 재실행 시 토글로 닫고 아니면 열기; 없으면 **`onClose()` 후 `item.onSelect?.()`**.
마우스 `onMouseMove` 로도 활성 인덱스가 바뀐다. 활성 행은 `scrollIntoView({ block: "nearest" })`.
**배경 스크롤 잠금**: `shouldRender` 동안 `window` 의 `wheel`/`touchmove` 를 **캡처 단계 · `passive: false`** 로 가로채 패널 밖이면 `preventDefault()`(이 앱은 스크롤 컨테이너가 body 가 아니라 `overflow: hidden` 만으로는 안 막힌다).
검색어가 바뀌면 `activeIndex = 0` 으로 리셋되고 열린 서브메뉴가 닫힌다. 필터는 `label` 또는 `description` 의 소문자 부분일치. 열릴 때 `query = ""`, `activeIndex = 0`, `submenu = null` 로 초기화한다.

카드 매핑에서 확정되는 것: `projectName = name.trim() || "Untitled Project"` · `createdAt = createdAt ?? updatedAt ?? latestGeneratedVideo.createdAt ?? new Date().toISOString()` · `type` 기본 `"canvas"` · **`mainImageUrl` 과 `nodeCanvasDocument` 는 항상 `null`** · `totalCount` 는 상태에 저장만 되고 어떤 UI 에도 노출되지 않는다.

##### 동적 썸네일

`canBuildDynamicThumbnail(card)`: highlight 타입 제외 · 빈 캔버스(v2 문서가 있고 노드 0개) 제외 · v2 노드가 1개 이상이면 true · 아니면 `nodeCanvasThumbnailUrl && nodeCanvasDocument`(후자가 항상 null 이라 이 화면에서는 false).

조건을 만족하면 브라우저에서 `renderArchiveCanvasV2ThumbnailBlob(doc, { theme, locale })` 로 그려 `URL.createObjectURL` 로 캐시한다. 캐시 키 `getDynamicThumbnailSignature` = `updatedAt | nodeCanvasThumbnailUrl | nodeCanvasV2UpdatedAt | v2 노드·엣지 JSON 지문 | shotMode | soundEnabled | theme | locale | ARCHIVE_V2_THUMBNAIL_SIGNATURE_TAG` — **테마나 로케일이 바뀌면 전량 재생성된다.** 렌더 실패는 조용히 저장 썸네일로 폴백하고, 후보에서 빠진 카드의 ObjectURL 은 revoke 된다.

videoedit 타입은 저장 래스터를 쓰되 `editorThumbnailUrlForTheme` 이 라이트에서 `/thumbnail.(png|webp)` → `/thumbnail-light.$1` 로 파생한다(쿼리 `tv=` 태그가 **3 이상**일 때만).

#### 상단 크롬 바 본체 — 빠져 있던 레이아웃 선언

위 「바 본체(`mainChromeTopBarInPanel`)」 표는 in-panel 문자열만 적었다. 한 줄 배치를 만드는 선언은 **베이스 `mainChromeTopBar`**(`Gnb.tsx:398-416`)에 있고, in-panel 은 이것들을 재선언하지 않으므로 그대로 실효값이 된다.

| --- | --- | --- |
| `box-sizing` | `border-box` | `Gnb.tsx:405` |
| `display` | **`flex`** | `Gnb.tsx:406` |

즉 실효 바는 **flex row · `align-items: center` · `gap: 8px` · `min-width: 0`** 이고, 좌 클러스터(`flex-shrink: 0`) · 가운데 `mainChromePageNav`(`flex: 1; min-width: 0; overflow: hidden`) · 우 프로필 클러스터(`flex-shrink: 0`)가 이 한 줄 위에 8px 간격으로 놓인다. 가운데만 늘어나고 양끝은 고정이며, `min-width: 0` 이 페이지 라벨의 `text-overflow: ellipsis` 를 실제로 동작하게 하는 조건이다.

`[&:not(.gnb-mainChromeTopBarInPanel)]` 가드가 붙은 `padding-right: max(12px, env(safe-area-inset-right,0px))` · `transition: left 320ms cubic-bezier(0.4,0,0.2,1)` · `pointer-events: none` 세 줄은 in-panel 인 이 화면에서 **적용되지 않는다**(`Gnb.tsx:404`,`412`,`413`).

> **`z-index: 1002` 는 in-panel 에서도 살아 있다.** in-panel 문자열은 `position: static` 만 재선언하고 `z-index`·`top`·`left`·`right` 는 건드리지 않는다(`Gnb.tsx:400-403`). `top/left/right` 는 static 박스에서 무시되지만, 이 바는 `mainChromeHeaderSlot`(`display: flex; flex-direction: column`, `appHomeSceneStyles.ts:787-795`)의 **플렉스 아이템**이라 static 이어도 `z-index` 가 적용되어 스택 컨텍스트를 만든다. 다만 헤더 슬롯 자체가 `z-index: 5` 로 이미 컨텍스트를 만들므로 이 1002 는 슬롯 안에서만 의미가 있고 페이지 층위와 경쟁하지 않는다.

(`render.ts:169-181` · `theme.ts:13-20`)

#### 프로젝트 카드는 키보드로 열 수 없다

카드 루트는 `<article>`(`AppHomeScene.tsx:1061-1090`)이고 `key` · `className` · `style` · `onClick` · `onContextMenu` · `onPointerDown` · `onPointerUp` · `onPointerLeave` · `onMouseEnter` · `onMouseLeave` 만 갖는다. **`role` · `tabIndex` · `onKeyDown` 이 없고 `aria-*` 도 없다.** `<article>` 은 네이티브 포커스 대상이 아니므로 Tab 순서에 들어가지 않고, 따라서 포커스 링이 그려질 여지 자체가 없다 — 카드를 여는 유일한 경로는 포인터 클릭이다. 이 씬의 `onKeyDown` 은 이름 변경 인풋 한 곳(`AppHomeScene.tsx:1210`)뿐이다.

버튼 쪽도 브라우저 기본 링이 남지 않는다. `globals.css` 는 `@layer base` **안에서** `button, input[type=button|submit|reset] { outline: none }`(`app/globals.css:1009-1014`)를 걸고, 레이어가 `1015` 에서 닫힌 뒤 **레이어 밖에서 한 번 더** `button:focus, button:focus-visible, button:active, input[type=button|submit|reset]:focus(-visible) { outline: none }`(`app/globals.css:1017-1027`)를 선언한다. 언레이어 규칙은 `@layer utilities` 의 Tailwind 유틸리티까지 이기므로, 더보기 버튼·드롭다운 아이템·배너 화살표/도트에는 커스텀 링을 명시하지 않는 한 어떤 포커스 표시도 나타나지 않는다.

즉 이 화면에서 눈에 보이는 포커스 표시는 **이름 변경 인풋의 `:focus-visible`** 과 **사이드바 토글의 `:focus-visible`** 둘뿐이며, 카드는 그 목록에 들어갈 수 없다(포커스 자체가 불가능).

- `onFocus` 로도 열리고 `onBlur` 로 닫힌다 — 포인터 전용이 아니다.
- 마운트 후 rAF 2회 뒤 열림 상태로 전환. 닫힘은 `transitionend`(`opacity`/`transform`) 로 언마운트하되 **180ms 폴백 타이머**가 있다. `suppress` 가 켜지면 페이드아웃 없이 즉시 제거된다.
- 표시 중 `scroll`(캡처) · `resize` 로 트리거 rect 를 다시 재 좌표를 갱신한다.
- **`prefers-reduced-motion` 분기가 없다.** 이 절 상태 표의 감소 모션 행이 열거하는 항목들과 달리 툴팁은 축소되지 않는다.
