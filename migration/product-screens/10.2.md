#### `[data-page-root]` — 이 그룹의 1번 계약

`globals.css` **맨 끝, `@layer` 밖**에 있다. 두 조건 모두 필수라고 주석이 못박는다.

**① 회색 램프를 팔레트 identity 로 고정한다.** `--gray-000`…`--gray-1000` 과 `-rgb` **22개 전부**.

| 토큰 | 라이트·다크 **양쪽** 해결값 |
| --- | --- |
| `--gray-000` | `#fafafa` |
| `--gray-100` | `#f1f1f3` |
| `--gray-200` | `#e3e4e8` |
| `--gray-300` | `#d5d7dd` |
| `--gray-400` | `#bcc0c9` |
| `--gray-500` | `#9aa0ab` |
| `--gray-600` | `#777d89` |
| `--gray-700` | `#575d68` |
| `--gray-800` | `#313640` |
| `--gray-900` | `#171b22` |
| `--gray-1000` | `#000000` |

> **이 세 라우트에서 `gray-*` 는 테마 반전 토큰이 아니다.** `html[data-theme]` 로 스코프된 `[data-page-root]` 재정의는 저장소에 **하나도 없다**.

같은 블록: `--theme-shadow-rgb`·`--theme-scrim-rgb` = `palette-gray-1000-rgb` · `--page-bg: var(--gray-1000)`(#000000) · `--panel: rgb(var(--gray-000-rgb)/6%)` · `--panel-strong: 10%` · `--line: 14%` · `--text-soft: 74%` · `--text-muted: 56%` · `--footer-safe-bottom: env(safe-area-inset-bottom)` · `--footer-reveal-height: 0px` · `position: relative` · `background: var(--page-bg)` · `color: var(--gray-000)`. `background` 는 **단축인 채로** 둔다(롱핸드 초기화 근거가 `pricing/page.tsx` 주석에 있다).

**② 줄바꿈 전역** (0,1,0):

```css
[data-page-root] :where(h1,h2,h3,h4,h5,h6,p,li,dt,dd,figcaption,blockquote,
                        a,button,label,legend,span,strong,em,small,td,th) {
  text-wrap: balance;  word-break: keep-all;
  overflow-wrap: break-word;  line-break: strict;
}
```

목록에 **`div` 는 없다.** 이 태그들에서 `text-wrap`/`white-space` 를 유틸리티로 세우려면 `!` 가 필수다 — 그래서 이 그룹의 모든 `text-balance!` · `whitespace-pre-line!` · `whitespace-nowrap!` 에 느낌표가 붙는다.

**③ 리빌 무력화** (0,2,0): `[data-page-root] [data-reveal] { opacity:1; transform:none; filter:none }`. 죽은 규칙처럼 보이지만 0,2,0 이라 자손 hover transform 을 이긴다.

**④ `/pricing` FAQ 램프 복구** (1,1,0): `[data-page-root] #pricing-faq { --gray-000: var(--palette-gray-1000); --gray-000-rgb: …; --text-soft: rgb(… / 0.74) }`. **이 규칙이 죽으면 가격 FAQ 글자가 흰색이 되어 사라진다.**

#### 놓치기 쉬운 것

- **`--spacing: 2px` 를 잊으면 전부 절반으로 틀린다.** 자주 나오는 값: `px-10`=20px · `pt-60`=120px · `pb-70`=140px · `pt-80`=160px · `pt-64`=128px · `pt-56`/`pb-56`=112px · `pt-44`=88px · `pt-41`=82px · `gap-6`=12px · `gap-8`=16px · `gap-12`=24px · `mb-28`=56px · `mb-22`=44px · `mb-16`=32px · `mb-14`=28px · `mt-80`=160px · `mt-32`=64px · `w-112`=224px · `w-28`=56px · `w-18`/`h-18`=36px · `h-19`=38px · `h-23`=46px · `h-17`=34px · `w-12`(도트 선택)=24px · `min-h-20`=40px · `scroll-mt-60`=120px. **곡률만 px 스케일이라 예외다** — `rounded-2`=2px · `rounded-6`=6px · `rounded-10`=10px · `rounded-24`=24px · `rounded-full`=999px.
- **레이어 밖 규칙이 유틸리티를 특이도와 무관하게 이긴다.** ① `[data-page-root] :where(…)` 줄바꿈 전역 → 모든 `text-balance!` · `whitespace-*!` ② `a { color: inherit; text-decoration: none }` → 링크 색·밑줄의 `!` ③ 이미 레이어 안인 `ui/Button` · `LanguageSelector` · 전역 `type-*` 위에 얹는 커스텀 → 겹치는 프로퍼티마다 `!`(단 `Button` 의 `html[data-theme=dark]` 중요 선언은 그 `!` 를 특이도로 다시 이긴다).
- **섹션 제목 잉크가 섹션마다 다르다.** `#overview` h2 = `text-gray-900` **#171b22**, `#capabilities`·`NodeCanvasShowcase` h2 = `text-palette-gray-900` **#171b22**, `#video-editor`·`#highlight`·`#pricing` h2 와 랜딩 FAQ 타이틀 = `text-gray-000` → **#000000**, `#final-cta` h2 = `text-gray-900` **#171b22**. 순검정과 #171b22 가 한 페이지에 섞여 있다.
- **`data-reveal` 은 이 그룹에서 시각 효과가 없다.** `SectionInteractions` 가 `.is-visible` 을 붙이지만 마케팅 스코프에 그 클래스를 스타일하는 CSS 가 없고, 반대로 `[data-page-root] [data-reveal] { opacity:1; transform:none; filter:none }`(0,2,0, 레이어 밖)이 항상 적용된다. `--reveal-delay: 40ms / 80ms / 80+80i ms` 는 **아무 효과가 없다.** (`SectionInteractions` 가 실제로 하는 일은 `--footer-reveal-height` 를 푸터 실측 높이로 세우는 것뿐이다.)
- **GNB 의 `activeSection` 옵저버는 죽은 코드다.** `menuItems` 3개가 전부 `route: true` 이고 `sectionId` 가 없어 `sectionElements.length === 0` → 즉시 return. navBlack 톤 전환은 **별개의 두 번째 옵저버**다.
- **GNB 로고 파일명이 직관과 반대다** — navBlack(밝은 배경)일 때 `/klipse-light.svg`, 어두운 배경일 때 `/klipse-dark.svg`.
- **`messages.nav.community` 의 실제 노출 문구는 '리소스'/'Resources'/'リソース' 다.** 코드 변수명·주석은 '커뮤니티'/'products'.
- **커뮤니티 드롭다운은 body portal + 인라인 `zIndex: 2000`** 이라 헤더(1001)보다 위다. 클래스의 `z-20` 은 무의미하다.
- **모바일 풀스크린 메뉴는 `z-[-1]` 이다.** 흔한 오버레이(z 높음) 패턴으로 옮기면 햄버거가 가려져 닫을 수 없게 된다.
- **`hover:` 를 쓰면 안 되는 자리가 많다.** Tailwind 의 `hover:` 는 `@media (hover: hover)` 로 감싸지는데 원본 모듈 CSS 의 `:hover` 에는 그 가드가 없었다. 히어로 CTA · 티어 버튼 · 티어 툴팁 · 푸터 링크 · 쇼케이스 탭 · 데모 안내 필 · 언어 옵션 · 워크스루 버튼·도트가 전부 `[&:hover]:` 나 `[…:hover_&]:` 를 쓴다 — **터치 기기에서도 hover 스타일이 걸린다.**
- **`border: 0` 을 `border-0` 으로 쓰면 안 된다** — `border-0` 은 폭만 0 이고 `--tw-border-style: solid` 가 남는다. 이 그룹은 전부 `[border:0]` / `[border:none]`. 같은 이유로 `rotate-45` 대신 `[transform:rotate(45deg)]`, `-translate-x-1/2` 대신 `[transform:translate(-50%,-50%)]`.
- **색 알파는 `rgb(var(--x-rgb) / 12%)` 형태의 임의값으로 옮긴다.** Tailwind 의 `/12` 단축은 `color-mix()` 로 컴파일된다.
- **주석 안에 유틸리티 문자열을 적으면 안 된다.** Tailwind 스캐너는 주석 속 후보도 규칙으로 만든다(실제로 dev 서버 CSS 파싱이 통째로 실패한 사고가 있었다).
- **`#capabilities` 데모의 aspect-ratio 는 0.64 이고, `CapabilitiesShowcaseDemoOnly.tsx:28` 의 주석은 틀린 상수(`LANDING_SHOWCASE_EMBED_ASPECT_RATIO`)를 지목한다.** 주석을 믿으면 틀린다.
- **`#capabilities` 는 `walkthroughPreset="helpGuide"` 라 9단계다.** `LANDING_WALKTHROUGH_STEP_COUNT`/`LANDING_WALKTHROUGH_NODE_IDS` 쪽(landing preset)은 이 화면에서 쓰이지 않는다.

#### `#overview` — `data-merge="done"` 은 애니메이션 경로에서 도달하지 않는다

앞의 상태표에 실린 `done` 열은 **감소모션 경로에서만** 실현된다. `prefers-reduced-motion: reduce` 이면 마운트 직후 `setMerge("done")` 하고 즉시 `return` 한다(`HomePageClient.tsx:695-698`) — 옵저버도 리스너도 걸리지 않는다.

애니메이션 경로에서 `done` 으로 넘기는 유일한 장치는 `animationend` 리스너인데, 조건이 성립하지 않는다.

- 리스너는 `#overview` 섹션에 걸리고 **`e.target === section`** 을 요구한다(`:743-748`).
- 그런데 `overviewBgReveal` 은 섹션이 아니라 자식 `OVERVIEW_LEAD` 박스에 걸려 있다 — `[[data-merge=on]_&]:animate-[overviewBgReveal_1200ms_cubic-bezier(1,0.01,0.41,0.99)_3180ms_forwards]`(`:159`).
- 섹션 자신(`OVERVIEW_SECTION`, `:109-127`)에는 애니메이션 선언이 **하나도 없다**. 그러므로 버블링으로 도달하는 모든 `animationend` 의 `target` 은 자손이고 조건은 언제나 거짓이다.
- 같은 파일의 주석(`:741-742`)은 "배경 애니메이션은 섹션 자신에 걸려 있으므로"라고 적어 코드와 어긋난다. 어느 쪽이 정본인지는 확정하지 않는다.
